# Plantillas contractuales

Coloca los modelos en `assets/` y consúltalos antes de redactar.

## Orden estándar de un contrato
Expositivos → Definiciones → Objeto → Obligaciones de cada parte → Precio y forma de pago → Duración y prórroga → Garantías → Responsabilidad y límites → Fuerza mayor → Confidencialidad → Protección de datos → Propiedad intelectual → Cesión y subcontratación → Causas de resolución → Efectos de la resolución → Notificaciones → Miscelánea → Ley aplicable y jurisdicción.

## Tipos y su cláusula crítica
| Tipo | Donde se juega el contrato |
|---|---|
| Prestación de servicios | Alcance, SLA y cambios de alcance |
| Suministro | Entrega, transmisión del riesgo, conformidad |
| Distribución / agencia | Exclusividad, indemnización por clientela |
| Licencia de software | Alcance de la licencia, soporte, responsabilidad |
| Desarrollo | Titularidad del resultado y aceptación |
| Confidencialidad | Definición de información confidencial y duración |
| Arrendamiento | Duración, renta, obras, garantías |
| Compraventa de participaciones | Manifestaciones y garantías, indemnidad, escrow |

## Reglas
- Una obligación por párrafo, sujeto siempre explícito.
- "Deberá" = obligación. "Podrá" = facultad. No los mezcles.
- Término definido: mayúscula inicial, definido una sola vez, usado siempre igual.
- Plazos con unidad expresa (naturales/hábiles) y día inicial identificado.
- Todo dato no facilitado se marca **[PENDIENTE: ...]**. Nunca se inventa.
